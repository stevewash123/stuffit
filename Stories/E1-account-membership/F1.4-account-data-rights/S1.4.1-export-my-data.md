# S1.4.1 Export everything

**Feature:** F1.4 Data export & account deletion  
**Phase:** MVP  
**Milestone:** M5  
**Depends on:** S7.5.3; S2.6.1  

As a **user**, I want to download all my data and files.

## Acceptance criteria
- One download with purchases, items, coverage, cards (last 4 only) and settings as readable files (CSV or JSON), plus all uploaded files
- Prepared in the background; the user is notified when it is ready; link expires

## Notes
Required by privacy law in several places and good practice everywhere.

## Status

Done (M5): Settings > Privacy & data > Download everything. A background job builds a zip: README, `account.json`, CSVs for purchases, items, coverage, cards (last 4 only), card benefits, private stores and brands, notifications, plus every uploaded file in a folder per purchase. CSV cells that start with = + - or @ are defused so a typed formula never runs; Excel-friendly UTF-8. Ready exports last 7 days, then the file is removed. One export builds at a time; the user gets a mandatory notification when it is ready. Only the requesting account is ever read. Tests: `CsvWriterTests`, `ExportTests`.

2026-11-02: every export failed on Render (UAT FS-27-13, "Could not be prepared") until fixed. Cause: the job read `temp.Length` after saving, and the Cloudinary store closes the stream it uploads (`ObjectDisposedException`); local disk does not, so tests passed. Fix: size is read before the save, and the test file store now closes the stream like Cloudinary. Rule: never touch a stream after handing it to `IFileStore.SaveAsync`. Still to confirm on Render after the deploy.
