# S1.4.2 Delete my account

**Feature:** F1.4 Data export & account deletion  
**Phase:** MVP  
**Milestone:** M5  
**Depends on:** S1.2.2; S2.6.1  

As a **user**, I want to delete my account and everything in it.

## Acceptance criteria
- Confirmation with the consequences spelled out; Stripe subscription is canceled first
- All account rows and every stored file are removed (cascade plus file-store cleanup; ConsignmentGenie-style orphaned files must not happen)
- Private stores, brands and policies go with the account; shared data stays
- Backups age out within a stated period, written in the privacy policy

## Notes
Closes the gap noted on S2.1.2: deleting an account must also delete its stored files.

## Status

Done (M5): Settings > Privacy & data > Delete my account (typed email plus password, then an in-app confirmation). Billing is cancelled first (`IBillingCanceller`; `NoBillingCanceller` until Stripe, which refuses if a subscription exists), then every stored file and export zip is removed before its record (a failure keeps the records and the account so nothing is orphaned and retry works), then all rows go in one transaction. Refused for an administrator, and for an account other people share (no invites yet). Wrong passwords count toward lockout. Shared reference data is untouched. Backups age out per the privacy policy wording (needs the real number). Tests: `AccountDeletionTests`, `privacy-security.spec.ts`.
