# S1.1.2 Reset a forgotten password

**Feature:** F1.1 Signup & authentication  
**Phase:** MVP  
**Milestone:** M1  
**Depends on:** S1.1.1 (Sign up and log in with email); S7.6.4 (Transactional and inbound email)  

As a **user**, I want to reset my password by email.

## Acceptance criteria
- forgot-password always answers 204, whether or not the email exists
- Reset link carries a URL-safe encoded token and expires (Identity token lifetime)
- Reset sets the new password and revokes every existing refresh token
- Invalid or expired link returns a ProblemDetails validation error on the token field
- Email goes through IEmailSender; development uses a logging sender until S7.6.4 provides a real provider

API implemented in StuffIt_API (branch m1-auth). UI screens pending.
