# S5.4.6 The real last day (shipping and drop-off time)

**Feature:** F5.4 Return and refund guidance  
**Phase:** v2  
**Milestone:** unassigned  
**Depends on:** S4.1.1 (Generate reminders from coverage dates), S5.4.2  

As a **user**, I want to know the last day I can start the return, not just the day the window closes, so mailing it does not make me late.

## Acceptance criteria
- Claim steps can say what counts as returned: dropped at the carrier, delivered to the store, or received by the seller
- Compute a **start by** date from the window end and a transit allowance for that route (stored value, default per route kind); shown beside the window end
- The final reminder before a return window closes uses the start-by date for mailed returns (S4.1.1)
- Show the assumption ("assumes 5 days in the mail"); the user can change the allowance on their purchase
