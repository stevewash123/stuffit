# S5.4.17 Question bank: ask only what matters

**Feature:** F5.4 Return and refund guidance  
**Phase:** v2  
**Milestone:** unassigned  
**Depends on:** S5.4.12; S5.4.13  

As a **developer**, I want the questions to come from data, so we ask few and the right ones for each product.

## Acceptance criteria
- Questions are reference data keyed by reason and category (TV, appliance, phone, furniture, tool, home system); each declares which eligibility rules it can change
- A question is asked only when two or more coverages would give different answers depending on it; if every route already agrees, skip it
- Category-specific questions where they matter (screen damage for a phone, "was it professionally installed" for an appliance, dead pixels for a TV)
- Order is stable and short; the wizard asks at most about five questions in total
- Operators add and edit questions in the admin area (E7); changes audited
- Unknown category uses the generic set
