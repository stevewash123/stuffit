# S5.4.5 Which route should I take? (refund versus repair)

**Feature:** F5.4 Return and refund guidance  
**Phase:** v2  
**Milestone:** unassigned  
**Depends on:** S5.1.2, S5.4.1  

As a **user**, I want to understand the trade-off between getting my money back and getting it fixed, so I pick the right route while the choice still exists.

## Acceptance criteria
- When more than one live route exists, show a plain comparison: what I get, what it costs me (time, shipping, fees), how long it usually takes, what I give up (a return ends manufacturer repair; a card claim may require filing first or within a short window)
- Warn about routes that close another: for example the return window ends tomorrow but the manufacturer warranty runs two more years
- A user can mark the intent (money back, repair, replace) and the order of routes changes to suit; the default order of S5.1.2 stays the starting point
- Statements about timing and what each route needs come from the sourced data; if we do not know, say we do not know
- The page never says a claim **will** be approved
