# S6.7.3 Redeem credits for free months

**Feature:** F6.7 Contribution credits  
**Phase:** future  
**Milestone:** Not planned  
**Depends on:** S6.7.1; S1.2.3  

As a **user**, I want to turn my credits into a free month.

## Acceptance criteria
- A set number of credits (for example 10) redeems one month through a Stripe customer balance or coupon, so billing stays in Stripe
- Redemption is shown in the plan page and the ledger
- Promotions can lower the price in credits for a period
