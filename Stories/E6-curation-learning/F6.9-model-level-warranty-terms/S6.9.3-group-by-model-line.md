# S6.9.3 Group observations by model line

**Feature:** F6.9 Model-level warranty terms from owners' documents  
**Phase:** future  
**Milestone:** M8  
**Depends on:** S6.9.2  

As the **system**, I want observations grouped by brand and model line, so hundreds of documents for one brand become a few countable groups.

## Acceptance criteria
- Group key: brand, product-tree node (the deepest one matched), start rule, term. Observations that placed on a node use it; the rest group by the longest shared normalised model prefix
- Per group: distinct accounts, agreeing accounts per term, date of the first and latest, how many were typed vs read from a document
- Unplaced model numbers collect in a "not in the tree" bucket per brand, with the numbers seen, so an operator can add a node or prefix (S6.9.4)
- Agreement uses the S3.2.5 combining rule; echo and unverified-email accounts do not count (S6.1.4)
- A burst of near-simultaneous uploads is flagged as a possible change to the brand's terms (S6.3.1), not counted as extra agreement
- Grouping is recomputed from the observations; it is never edited by hand
