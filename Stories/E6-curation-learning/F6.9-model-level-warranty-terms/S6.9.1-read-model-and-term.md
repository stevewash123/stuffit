# S6.9.1 Read the model and term from an uploaded warranty document

**Feature:** F6.9 Model-level warranty terms from owners' documents  
**Phase:** future  
**Milestone:** M8  
**Depends on:** S6.6.1 (Upload the official warranty document); S3.2.8 (product tree, built; no story file yet)  

As the **system**, I want to read the model, the term and the start rule from a warranty document an owner uploaded, so each document can be counted as evidence for the right model line.

## Acceptance criteria
- The document reading (already stored as `Document.Text`, class `warranty_document`) also yields: brand, model number or reference number as printed, term in months, start rule, component terms if listed, and the sentence the term came from
- Model numbers are normalised with `ModelNumbers.Normalize` and placed in the brand's product tree with the existing matcher (exact, then prefix, then name); the match kind and confidence are kept
- A quote that does not appear in the document text is dropped, as for store and brand pages
- Nothing is read that is not on the document: a missing model or term stays empty, never guessed from the brand
- The owner can correct any extracted value before it counts; a corrected value is marked as typed, not read (S3.2.5)
- A document that is not a warranty (receipt, manual) yields nothing here
