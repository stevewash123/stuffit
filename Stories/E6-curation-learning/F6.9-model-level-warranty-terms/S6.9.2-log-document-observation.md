# S6.9.2 Log a document observation

**Feature:** F6.9 Model-level warranty terms from owners' documents  
**Phase:** future  
**Milestone:** M8  
**Depends on:** S6.9.1; S6.2.1 (observation logging); S6.1.6 (sharing default)  

As the **system**, I want each confirmed document reading recorded as one shared observation, so agreement can be counted later.

## Acceptance criteria
- Recorded only when the owner chose "this came with this purchase" and sharing is on and this document was not skipped in the redaction preview (S6.1.6); otherwise the document stays private and nothing is logged
- One row holds: brand, product-tree node (or the normalised model number when unplaced), category, term in months, start rule, component terms, quote, document content hash, evidence kind (document read / typed), date
- Never holds the owner, account, serial number, order or purchase details, or the file. The account is kept only as an internal distinct-count key that is never shown or exported
- One account counts once per brand and model line and term, however many documents it uploads; the same content hash from different accounts counts for each account but is linked as one file for review
- A suggestion the owner only accepted (echo) is not logged as an observation (S6.2.1)
- Deleting the document or the account removes its observation and the counts update
