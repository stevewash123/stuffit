# S6.3.3 Ask affected users to confirm their policy

**Feature:** F6.3 Automated policy-change detection & user confirmation  
**Phase:** v2  
**Milestone:** M7  
**Depends on:** S6.3.2 (AI checks the change against the official source); S4.4.3 (Dispatcher: store preferences and enforce them on every send); S4.5.4 (Actionable notifications)  

As a **user**, I want to be asked to confirm or update my card benefit when it may have changed.

## Acceptance criteria
- Targets accounts holding that card product (payment_method to card_benefit)
- Delivered as an actionable in-app notification (S4.5.4) and, per preferences, email
- Message: Some Citi cardholders report a change to [benefit]. Please check yours and confirm or update it.
- One-tap: keep current, update to new value, or not sure
- Responses feed back as fresh confirmations (confirmed_at) and as independent evidence
- Rate-limited; a user is never sent more than one change prompt per card per period
- Wording for unverified changes stays neutral; verified changes cite the source
