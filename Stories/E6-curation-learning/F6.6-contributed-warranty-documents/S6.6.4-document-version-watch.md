# S6.6.4 Watch for new versions of a warranty

**Feature:** F6.6 Contributed warranty documents  
**Phase:** v2  
**Milestone:** M7  
**Depends on:** S6.6.3; S6.3.1; S6.4.2  

As a **system**, I want to notice when a warranty document changes.

## Acceptance criteria
- Each Confirmed document keeps its source link and content hash
- Scheduled re-check of the source; a different hash or text raises a change signal (S6.3.1)
- A newer document uploaded by someone else is compared with the stored one
- An accepted new version supersedes the old one: the old stays in history with dates, affected users are notified (S6.3.3), existing coverage keeps its snapshot
