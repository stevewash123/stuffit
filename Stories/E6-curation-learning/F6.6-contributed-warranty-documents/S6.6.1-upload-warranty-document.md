# S6.6.1 Upload the official warranty document

**Feature:** F6.6 Contributed warranty documents  
**Phase:** v2  
**Milestone:** M7  
**Depends on:** S2.1.2; S3.1.1  

As a **user**, I want to attach the official warranty or return terms to my item.

## Acceptance criteria
- Upload a PDF or screenshot to an item or a coverage, typed as warranty terms; optional link to where it came from
- The coverage shows it is backed by a document (a stronger source than a suggestion)
- Stored privately with the user; submission for sharing is a separate, explicit choice
- Content hash recorded so the same file is recognized

## Sharing
Shared by default with opt-out (S6.1.6): the document is scanned for personal information, redacted, and the member sees a preview before anything is shared; they can share the redacted copy or skip. The extracted facts are recorded as a claim (S6.1.4) unless sharing is off or the document was skipped. Nobody else sees a claim until an operator verifies it. Receipts, registration cards and custom-term contracts always go through the redaction check.

**Reopened 2026-11-04:** the "Stored privately; submission for sharing is a separate, explicit choice" criterion above now reads: private by default in the member's account, shared by default under S6.1.6 unless they opt out.
