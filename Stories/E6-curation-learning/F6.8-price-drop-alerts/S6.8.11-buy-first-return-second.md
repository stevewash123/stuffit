# S6.8.11 Buy first, return second

**Feature:** F6.8 Price-drop alerts during the return window  
**Phase:** future  
**Milestone:** Not planned  
**Depends on:** S5.4.6 (The real last day), S5.4.7 (Track a return), S6.8.9  

As a **user**, I want the steps in a safe order, so I am not left with nothing if the new order falls through.

## Acceptance criteria
- First step: confirm the sale price still applies and the item is available, with delivery date, before placing the new order; never return the original on the strength of a price that has not been secured by a confirmed order
- Suggested order: place the new order, wait for it to arrive and check it, then return the original; the original is the fallback
- Rebuy lead time (order, ship, arrive) is estimated and compared with the real last day; if it will not fit, say so and do not alert (feeds S6.8.2)
- Tracks both legs: the new order (expected delivery) and the return (S5.4.7), with a reminder before the return deadline
- The new purchase becomes a new item with its own return window and coverage; the old one is marked returned and refunded (S5.4.11) when done
- The amount recovered recorded is the **actual** net saving, not the estimate
