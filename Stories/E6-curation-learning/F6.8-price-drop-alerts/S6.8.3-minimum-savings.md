# S6.8.3 Minimum savings threshold

**Feature:** F6.8 Price-drop alerts during the return window  
**Phase:** v2  
**Milestone:** M9  
**Depends on:** S6.8.1  

As a **user**, I want to set how big a drop must be before I am told, so small differences do not interrupt me.

## Acceptance criteria
- Threshold is the larger of a dollar amount and a percentage of the price paid: both are settings (proposed defaults $10 and 5%, to confirm)
- Compared against the savings the user can actually get: Stage 1, the price difference; Stage 2, the **net** savings from S6.8.9 (never the sticker difference)
- Currency-aware: the threshold is in the purchase's currency
- Per-purchase override, as in S6.8.1
- Raising the threshold does not delete earlier alerts; lowering it does not send old ones
