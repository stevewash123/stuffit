# S6.8.5 Does this store adjust prices?

**Feature:** F6.8 Price-drop alerts during the return window  
**Phase:** v2  
**Milestone:** M9  
**Depends on:** S5.4.13 (Eligibility rules as data), S5.4.2 (Claim steps are versioned reference data)  

As a **user**, I want to be told only when the store actually adjusts prices, so the alert is not a false hope.

## Acceptance criteria
- Price-adjustment terms are reference data per seller: whether offered, window length, what is excluded (clearance, doorbusters, marketplace sellers, online versus store prices), proof needed
- Alert is sent only if the seller is known to adjust and the item is not excluded; if the policy is unknown the alert is not sent (S6.4.6 can still send its generic reminder)
- Sale-event pricing (S6.8.4) is treated as excluded unless the seller's policy says it adjusts to event prices; when the policy is silent, the alert is held back or sent with the strong disclaimer of S6.8.6, never as a plain drop
- The alert shows the window, the exclusions that applied, and the source and last-verified date of the policy
- A seller with no adjustment policy gets no Stage 1 alert (Stage 2 may still apply)
- Card price protection (S6.4.6) is a separate source and can be a second route on the same alert
