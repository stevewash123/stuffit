# S9.1.3 Inline quick-add, expand for details

**Feature:** F9.1 App shell & navigation  
**Phase:** MVP  
**Milestone:** M1  
**Depends on:** S9.1.1 (Responsive, mobile-first layout)  

As a **user**, I want to enter only the basics up front and open more detail only when I want it.

## Acceptance criteria
- Pattern: every create form starts with a compact inline row of essential fields only
- An Expand control opens the same record in place, or a Details pop-out (drawer/modal) for longer forms
- Record is valid and saved with essentials alone; details are optional and can be added later
- Expanding or popping out never loses what was already typed
- Inline-created records show a subtle incomplete marker until key details are filled
- Pop-out keeps the parent form intact (e.g. adding a seller while entering a purchase)
- Same pattern and components used for purchase, item, coverage, party, policy and card

## Notes
UI convention story. Other E9 stories follow it.
