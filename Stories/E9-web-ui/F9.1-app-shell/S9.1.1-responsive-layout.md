# S9.1.1 Responsive layout for phone and desktop

**Feature:** F9.1 App shell & navigation  
**Phase:** MVP  
**Milestone:** M1  
**Depends on:** S7.6.1 (Environments and deployment)  

As a **user**, I want to use the app comfortably on my phone or on a computer.

## Acceptance criteria
- Designed for both: equal quality on a phone and on a desktop (about half the use is expected on each)`r`n- Phone: works at phone width with no horizontal scroll, large tap targets`r`n- Desktop: uses the width (multi-column layouts, tables for lists, keyboard-friendly forms), not a stretched phone layout
- Primary nav: Home, My Items, New Items, Cards, Notifications, Settings
- Header carries the notification bell (S4.5.2)
- Large tap targets, plain language, no jargon
- Accessible contrast and keyboard navigation
