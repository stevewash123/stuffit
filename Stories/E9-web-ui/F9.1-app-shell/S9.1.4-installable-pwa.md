# S9.1.4 Installable on a phone (PWA)

**Feature:** F9.1 App shell & navigation  
**Phase:** MVP (launch polish)  
**Milestone:** M5  
**Depends on:** S9.1.1 (Responsive, mobile-first layout)  

As a **user**, I want to add StuffIt to my phone's home screen and have it open like an app, so it is one tap away when something breaks.

## Acceptance criteria
- Web app manifest (name, icons, theme color, standalone display) and a service worker that caches the app shell
- Installable on Android and iOS; a short, dismissible how-to for adding it to the home screen on iOS
- An offline fallback page; the app shows a clear message instead of a blank screen when the network is down
- Update prompt when a new version is available
- Receipt and photo upload uses the phone camera directly (file input with capture)
- Web push is out of scope here; it is decided with the notification channels (F4.3)

## Notes
The native wrapper (Capacitor) for share-sheet intake and reliable push is S9.1.5, planned after the proof of concept and before going live.

## Status

Done (M5): web app manifest (standalone, theme colour, three icons including a maskable one, two shortcuts), service worker that caches the app shell and never API data, update prompt (Reload), offline notice, iPhone/iPad add-to-home-screen how-to (dismissible), camera upload via the existing Take a photo button (capture=environment). Verified in a production build in real Chrome: the service worker registers and the app opens offline with the notice. Not verified on a real iPhone or Android phone. Tests: `pwa.spec.ts`.
