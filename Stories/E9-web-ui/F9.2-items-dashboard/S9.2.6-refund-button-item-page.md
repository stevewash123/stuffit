# S9.2.6 Refund button and coverage summary on the item page

**Feature:** F9.2 Items list & dashboard  
**Phase:** MVP candidate  
**Milestone:** unassigned  
**Depends on:** S9.2.3 (Item detail page); S5.4.12 (Refund wizard)  

As a **user**, I want a clear Refund button on my item that starts the guided help, and a quick read of where I stand.

## Acceptance criteria
- A primary **Refund** button in the item header, plus a panel "Need to return it or make a claim?" with "Start a refund or claim"; both open the wizard (S5.4.12)
- Header badge states the most urgent fact in words ("Return window closes tomorrow", "Covered until June 2028"), using the earliest end date when the date is approximate (S3.1.6)
- Coverage list in the order to try them, each with provider, dates, status and the plain terms; coverage not yet started says when it starts
- The item and purchase blocks sit side by side on desktop and stack on a phone; receipt and files listed under the coverage
- Refund is hidden for an item already marked returned or disposed; "I got my money back" (S5.4.11) shows in its place if no recovery is recorded
- Item in a household: any person on the item can start it (S9.2.4)

## Status
Mock built at `/items/sample` on sample data (a TV bought 14 days ago, return window closing tomorrow, maker warranty, card extension). The real item page gets the button when S5.4.12 exists.
