# S9.9.1 New Items list

**Feature:** F9.9 New Items inbox  
**Phase:** v2  
**Milestone:** M6  
**Depends on:** S2.2.5 (Pending items and their API); S3.1.5 (Default coverage for a pending item); S9.1.1 (Responsive layout for phone and desktop)  

As a **user**, I want to see everything WarrantyCat picked up for me but has not finished, so I can finish it or skip it.

## Acceptance criteria
- Route `/add`, tab "New Items"; newest first
- Each row: item name (or "Unnamed item"), store, date, total; a badge for the source (Email or Receipt upload) and the email subject or file name
- Missing fields listed per row (item, store, date, total)
- Default coverage shown as chips, each labelled with where it came from (store, card, maker); a row with none says no warranty was found yet
- Empty state explains how to forward a receipt and offers "Add a purchase"
- "Add one yourself" opens the blank purchase form at `/add/new`
- Works on phone and desktop; buttons wrap on narrow screens

## Status
Done (2026-10-02): the page reads `GET /api/pending-items` through `core/inbox.api.ts`; the sample data is gone. Also has "Upload a receipt" (S2.2.6). Until email capture (S2.2.2) exists, the only rows are receipt uploads, which arrive with every field missing.
