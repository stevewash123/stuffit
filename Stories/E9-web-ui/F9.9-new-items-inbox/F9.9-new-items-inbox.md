# F9.9 New Items inbox

**Epic:** E9 Web app UI (core screens)  
**Phase:** v2 (page built early with sample data; real data arrives with email-in, M6)

The "New Items" tab: purchases we spotted in forwarded emails and receipt uploads, partly filled in, waiting for the user. Each row shows what we know, where it came from, what is missing and the default coverage we can attach (from the store, the card used or the maker). Per row the user can **Add Details**, **Accept** (only once at least one coverage is attached) or **Dismiss** (do not track). Accepted items move to **My Items**.

The API behind it is S2.2.5; default coverage is S3.1.5.
