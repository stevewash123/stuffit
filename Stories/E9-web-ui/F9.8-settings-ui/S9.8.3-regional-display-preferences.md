# S9.8.3 Region and display preferences

**Feature:** F9.8 Settings & user configuration  
**Phase:** v2  
**Milestone:** M8  
**Depends on:** S9.8.1 (Settings page)  

As a **user**, I want dates, times and money shown the way I read them, so the app does not look foreign to me.

## Acceptance criteria
- Profile settings gain country, currency, date format (MM/dd or dd/MM) and 12 or 24 hour time
- Defaults come from the browser locale at signup and can be changed; every date, time and money display reads the saved choice
- Country also picks the reference data used for return-law defaults and the card catalog; reference data only suggests, the item records what the user entered
- Stored as typed columns beside Timezone on the user profile, one value in one place; new options are added as columns, not a key-value bag
- Changes to profile and security settings are written to the audit log with old and new values (same shape as admin audit)

## Notes
From the ConsignmentGenie owner settings review (`docs/consignmentgenie-owner-settings-review.md`): V1 keeps `ShopTimezone`, `Currency`, `DateFormat` and `TimeFormat` on the organization. StuffIt already has `Timezone` and `DigestTime` on the user (S9.8.1), but no country, currency or formats. V1 stored the same value in several places (column, JSON page, DTO) and needed a sync hack; do not repeat that. V1 wrote no audit rows for settings changes.
