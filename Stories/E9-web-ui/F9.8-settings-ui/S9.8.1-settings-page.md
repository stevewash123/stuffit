# S9.8.1 Settings page

**Feature:** F9.8 Settings & user configuration  
**Phase:** MVP  
**Milestone:** M1  
**Depends on:** S9.1.1 (Responsive, mobile-first layout); S1.1.1 (Sign up and log in with email)  

As a **user**, I want to manage my profile, notifications and plan in one screen.

## Acceptance criteria
- Tabs or sections: Profile, Notifications, Cards, Plan and billing
- Profile: name, email, timezone, password change
- Notifications tab hosts the preference grid (S4.4.2)
- Plan and billing tab is the plan page (S1.2.4) once it ships; until then a simple plan summary

## Status

Update (M4): Profile can now save the time zone and the preferred reminder time (`PUT /api/me/profile`); Notifications tab is the preference grid. Still open: changing the name and password.
