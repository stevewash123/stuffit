# S9.8.4 Setup checklist and dismissals

**Feature:** F9.8 Settings & user configuration  
**Phase:** v2  
**Milestone:** M8  
**Depends on:** S9.1.2 (Empty states and first-run guidance); S9.8.1 (Settings page)  

As a **new user**, I want a short list of what to set up next that I can dismiss for good, so I get started without being nagged.

## Acceptance criteria
- A checklist of first steps (add a card, add a first purchase, forward a receipt email, turn on reminders) shows progress and ticks itself as each is done
- Each step can be skipped, and the whole checklist can be dismissed; dismissals are saved with the user and never reappear
- Completion time is stored once all steps are done or the list is dismissed
- Unavailable options in settings are shown disabled with the reason ("SMS needs a verified phone"), not hidden

## Notes
From the ConsignmentGenie owner settings review: V1 tracks `SetupStep`, `SetupCompletedAt`, `OnboardingDismissed`, `WelcomeGuideCompleted` and `SetupChecklistDismissed`, and its settings menu supports `disabled` with `disabledReason`. Keep persisted flags on the user, not in browser storage, so dismissal follows them across devices.

Not built. S9.1.2 covers empty states only.
