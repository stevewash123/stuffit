# S9.8.2 Choose a color theme

**Feature:** F9.8 Settings & user configuration  
**Phase:** v2  
**Milestone:** M8  
**Depends on:** S9.8.1 (Settings page)  

As a **user**, I want to pick a color theme, so the app looks the way I like.

## Acceptance criteria
- A theme picker in settings lists preset themes plus "Match my device" (light or dark)
- The choice is saved with the user's preferences and applied at sign-in on every device; until a choice is made the default theme applies
- Each theme defines every token in `styles.css` (surface, text, brand, on-brand, danger, backdrop and so on) for light and dark, and meets contrast: body text 4.5:1 on its surface, on-brand text 4.5:1 on its brand color
- No page or component uses a literal color; everything reads the tokens

## Status
Groundwork done (M4 session): all colors are theme tokens under `:root[data-theme="teal"]` with a dark variant, `data-theme="teal"` is set in `index.html`, and no component hardcodes a color. Adding a theme means adding a token block and setting the attribute. The picker and saving the choice are not built.
