# S9.10.4 Say certainty in words, one way, on every screen

**Feature:** F9.10 UI structure and honesty  
**Phase:** v2  
**Depends on:** none for the words; S2.8.4 for the rest

As a **person**, I want a match to be described the same way wherever I see it, and never as a percentage.

## Acceptance criteria
- One presenter turns the API's `decision`, `confidenceBand` and `reason` into the word, tone and explanation. Add purchase, New Items, the item page and reading review use it (F6).
- The item page tooltip no longer shows a percent. If a percent is wanted it sits behind an explicit "Why this score?": a product decision recorded here.
- The numeric thresholds in `certainty.ts` and the copies in add purchase (`TICKED_FROM`, the attached-paper fit values), item detail (`PickedFrom`, inline `>= 0.8`) and New Items are deleted once S2.8.4 ships.
- Reading review's high/medium/low maps to the same words, or is documented as a separate pipeline.

## Notes
Part one (words, no percents) can go first; part two follows S2.8.4.
