# S9.10.5 Follow the server's decision when ticking and applying

**Feature:** F9.10 UI structure and honesty  
**Phase:** v2  
**Depends on:** S2.8.4; S9.10.7

As a **person adding a purchase or accepting a new item**, I want the screen to tick what the server is sure of and ask me about the rest, the same in quick add and the full form.

## Acceptance criteria
- Pre-ticking, quick add and the item page's suggestions use `decision`; the client computes no 80% rule (F1).
- Document facts skip the review panel only when the API marks the whole batch `auto` and every store and brand id is already known; otherwise the review panel opens (F4). Until S2.8.4 exists, the panel opens whenever a proposal has no party id.
- No store or brand is created as a side effect of applying facts without the person seeing it.
- Quick add and the full form give the same attachments for the same arrival (a spec posts both).
