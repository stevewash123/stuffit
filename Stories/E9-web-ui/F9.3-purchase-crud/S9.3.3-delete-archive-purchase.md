# S9.3.3 Delete or archive a purchase

**Feature:** F9.3 Purchase create / edit / delete  
**Phase:** MVP  
**Milestone:** M3  
**Depends on:** S9.3.1 (Create a purchase)  

As a **user**, I want to remove a purchase or mark items returned or disposed.

## Acceptance criteria
- Confirmation before delete
- Item status: owned, returned, disposed; reminders stop for non-owned
- Deleting removes attached files and pending reminders


## Status
Done (M3): soft delete of purchase or item with an in-app confirmation; coverage and files are removed. Returned and gone statuses are set on the item.
