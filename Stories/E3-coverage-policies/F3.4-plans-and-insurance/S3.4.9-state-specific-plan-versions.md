# S3.4.9 State-specific versions of a plan agreement

**Feature:** F3.4 Plans and insurance you hold  
**Phase:** v2  
**Milestone:** M9 (proposed)  
**Depends on:** S3.4.5 (shared plan types); S3.4.2 (read the contract); F6.3 (policy change detection)  
**Found by:** Steve, 2026-10-27: the sample contract is Texas, and he has several others specific to other states.

As a **user**, I want the terms I see for my plan to be the ones for my state, so a cancellation window or refund rule in my contract is not replaced by another state's.

## Why this matters
Home warranty agreements are regulated by state and companies publish a version for each (the 2-10 sample is a Texas agreement). State versions commonly differ in the cancellation window, refund of unused premium, how a renewal is noticed, whether the service-fee rules differ, who regulates the company, and the complaint contact. A shared plan type (S3.4.5) that ignores the state would pass one state's terms to everyone.

## Acceptance criteria
- A plan type can have **state variants**: the base terms, with differences for named states, each with its own source document. A plan type with no variant for a state uses the base and says "No version for <state> yet".
- A plan records its **state** (from the covered home's address, S3.4.7). The terms shown, the cancellation window and the regulator's contact come from the matching variant.
- Reading a contract (S3.4.2) recognizes the state from its title or address and tells the person which variant it appears to be. A contract that differs from the variant on file is marked "your contract says X; the shared record says Y", not overwritten. The user's contract always wins for their own plan.
- **Operators** can add a state variant from an uploaded agreement or an official source address, with the same source-and-quote check as other reference data (S3.2.5). Several variants are readable together as a comparison, so a difference between two states is listed, not found by reading both.
- **Change watching** (F6.3) covers each variant's source document; a changed agreement is offered to the people holding that plan as an update (S3.4.2), not applied silently.
- No legal advice: the page shows what the document says and where, and never what the person's rights are.

## Open questions
- Which states to do first. Start with the states users actually hold plans in, learned from contracts they upload, rather than all fifty.
- Whether non-US versions are in scope. Not for now.
