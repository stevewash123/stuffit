# S3.3.5 Change the number for a card

**Feature:** F3.3 Payment methods & card benefits  
**Phase:** MVP  
**Milestone:** M4  
**Depends on:** S3.3.1 (Add a card)  

As a **user**, I want to change the last 4 digits when my bank issues a new card on the same account, so receipts for the new card still match this card and older receipts still match too.

## Acceptance criteria
- A card's page shows its current digits as `XXXX-XXXX-XXXX-0281`. Once it has digits, the plain "add last 4" box is not shown
- **Change the number for this card** (tooltip: use this when your bank issues a new card on the same account; the old digits are kept so older receipts still match) opens a "New last 4" box with Save and Cancel
- `POST /api/payment-methods/{id}/last4` with `replaceCurrent: true` ends every current number today (valid-to = today) and adds the new one valid from today with no end date
- Replaced numbers stay on the card, listed as "previous number, still matched on receipts", each removable. Receipt matching (S3.3.3) uses current and previous numbers
- The same digits cannot be added twice to one card (409)
- Never a full card number: exactly 4 digits
- A card with no digits (added before last 4 became required) still offers the plain "Last 4" add box
