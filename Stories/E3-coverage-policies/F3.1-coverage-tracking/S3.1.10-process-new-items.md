# S3.1.10 New Items are processed, not computed on every look

**Feature:** F3.1 Coverage tracking
**Phase:** v2
**Milestone:** M6
**Depends on:** S3.1.5 (default coverage for a pending item); S2.2.5 (pending items API)

As a **user**, I want New Items to load fast and stay right when shared data changes, so the list never makes me wait and never shows a warranty that is out of date.

## Principle
Everything about a New Item that comes from shared data is temporary until the user Adds it. It is worked out by **processing** and stored with the item; listing only reads what is stored. Add copies what the user keeps into real coverage (S3.1.1).

## Acceptance criteria
- Each New Item has a stored list of the policies that may cover it (store return window, maker's warranty, card benefits), each with a status: Applies (80% or more, what a quick add attaches), May apply (60% or more), Doubtful. Rows hold the source party and policy ids, so a change to a store, brand, card issuer or policy finds the items that use it.
- Processing = match what is still empty from shared data (store, brand, category, card by last 4) then replace the item's policy list. It never overwrites what the user set.
- An item is marked as needing processing by: any edit to its facts, a new item, and any change to shared data (parties, categories, models, product nodes, policies, evidence, card benefits) or to the person's own cards. Shared changes mark everyone's waiting items; a private row or a person's card marks that account's.
- The list is a page of 10 (up to 50), newest first, with the total. It reads stored rows only. Items still marked come back as stored, flagged `processing`, and a background run is requested for the account (not more than once every 2 minutes per item). The screen shows "Updating…" and looks again every few seconds.
- One item looked at on its own (open, edit, Add) is brought up to date at once. Two requests at the same moment do not fail: one wins, the other reads the result.
- Safety net: a 15-minute run processes anything still marked, for every account.
