# S3.2.1 Party and versioned policy tables

**Feature:** F3.2 Reference data & versioned policies  
**Phase:** MVP  
**Milestone:** M2  
**Depends on:** S7.5.1 (DDL: reference data schema)  

As a **developer**, I want to reference tables that keep policy history.

## Acceptance criteria
- Single party table with role flags
- seller_policy, manufacturer_policy, card_benefit carry effective_from/to, source_url, verified_at
- Exclusion constraint (btree_gist) blocks overlapping ranges
- Lookup by purchase date; falls back to earliest version and flags it


## Status
Done (M0 schema, M2 service). Versioned write rules in ReferenceService; lookup with category fallback and out-of-range flag in PolicyLookupService.
