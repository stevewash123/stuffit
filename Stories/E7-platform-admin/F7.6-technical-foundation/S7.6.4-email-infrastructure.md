# S7.6.4 Transactional and inbound email

**Feature:** F7.6 Technical foundation  
**Phase:** MVP (outbound), v2 (inbound)  
**Milestone:** M0  
**Depends on:** S7.6.1 (Environments and deployment)  

As a **developer**, I want to send reminders and later receive forwarded receipts.

## Acceptance criteria
- Outbound provider with SPF/DKIM/DMARC configured; sender address and app base URL come from configuration
- Supports the compliance headers and footer from S4.4.8
- Inbound webhook provider evaluated and chosen for email-in (F2.2)
- Bounce and complaint handling feeds delivery tracking (S4.4.3)
- API keys and secrets live in environment configuration, never in the repository

## Notes
Technical story. ConsignmentGenie uses Resend and hardcodes the sender and base URL.
