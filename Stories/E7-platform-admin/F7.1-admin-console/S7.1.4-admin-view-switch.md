# S7.1.4 Switch between admin and customer view

**Feature:** F7.1 Admin console  
**Phase:** v2  
**Milestone:** M7  
**Depends on:** S7.1.3  

As an **administrator**, I want to use StuffIt as a normal customer with my own purchases when I want to.

## Acceptance criteria
- A visible switch in the header moves between the admin view and the customer view of the same account
- The customer view is exactly what customers see, so the administrator can test it
- The current view is obvious at a glance (label and color) so admin actions are not taken by mistake

## Status

Done: a Customer view / Admin view switch in the header and the account menu. The admin side is marked with an Admin badge and its own navigation; the customer view is the normal app. The choice lasts until the tab is closed. Not done: a color change for the admin side.
