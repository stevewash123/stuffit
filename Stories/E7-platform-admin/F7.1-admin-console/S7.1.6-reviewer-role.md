# S7.1.6 A limited reviewer role

**Feature:** F7.1 Admin console  
**Phase:** future  
**Milestone:** M8  
**Depends on:** S7.1.3  

As an **administrator**, I want to let a helper review submissions without full administrator power.

## Acceptance criteria
- A reviewer can work the review queues (confirm, reject, ask for another look) but cannot change billing, other administrators, credits rules or user data
- Roles are a small fixed set (customer, reviewer, administrator), not per-screen permissions
- Reviewer actions are audited the same way

## Notes
Only if the review volume outgrows one person. Customers stay one role; this is an internal staffing question.
