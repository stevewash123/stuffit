# S7.7.7 A test keeps controllers off the database

**Feature:** F7.7 Code health  
**Phase:** MVP  
**Milestone:** M5  
**Depends on:** S7.7.3 to S7.7.6 (start with an allowlist of the controllers not yet done and shrink it)  

As a **developer**, I want the structure held by a test, not by memory.

## Acceptance criteria
- A unit test fails if any class in `StuffIt.Api.Controllers` takes `StuffItDbContext`, except an explicit allowlist (starts as the controllers not yet cleaned up; ends with only `MaintenanceController`).
- A second check that `StuffIt.Core` references no other project and `Infrastructure` does not reference `Api`.
- Optionally a size guard: a failing test for a source file over a set number of lines, with an allowlist of existing offenders.
