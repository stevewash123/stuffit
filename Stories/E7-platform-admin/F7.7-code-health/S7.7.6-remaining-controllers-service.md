# S7.7.6 The remaining controllers use services

**Feature:** F7.7 Code health  
**Phase:** MVP  
**Milestone:** M5  
**Depends on:** none  

As a **developer**, I want the last controllers that touch the database to go through services.

## Acceptance criteria
- `PurchaseControllers`, `ItemBrowseControllers`, `NotificationControllers`, `MeController`, `TwoFactorController`, `BotController`: each query moves into a service (an existing one where it fits).
- `MaintenanceController` is the one allowed exception (migrate and seed are operations on the database itself); it stays small and key-guarded.
- Routes and responses unchanged; tests pass.
