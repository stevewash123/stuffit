# S7.7.5 Reference and admin controllers use services

**Feature:** F7.7 Code health  
**Phase:** MVP  
**Milestone:** M5  
**Depends on:** none  

As a **developer**, I want the reference-data, admin party-notes, web-data and admin controllers to call services, not the database.

## Acceptance criteria
- `ReferenceControllers`, `AdminPartyNotesController`, `WebDataController` and `AdminController`: queries and rules move into the existing reference services (or a small new one per area). Where a service already exists, use it.
- Audit-trail writes stay in the services, never in the controller.
- Routes and responses unchanged; tests pass.
- None of the four references `StuffItDbContext`.
