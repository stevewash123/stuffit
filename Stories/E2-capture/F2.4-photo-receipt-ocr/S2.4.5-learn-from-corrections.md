# S2.4.5 Keep what the person corrected

**Feature:** F2.4 Photo and document reading  
**Phase:** v2  
**Milestone:** M7 (proposed)  
**Depends on:** S2.4.2; S2.4.3  

As the **builder**, I want to know when a person changes a value the reader filled in, so real mistakes become test cases and I can see which fields the reader gets wrong.

## Acceptance criteria
- When a New Item is added (or quick added) with a field different from what was read, store: the field, the value read, the final value, the confidence, the model and the prompt version. Nothing else from the document.
- A field the person left alone is counted as confirmed, so there is a rate and not only a list of errors.
- A report command shows, per field and per model, how often the reading was corrected.
- Corrections can be turned into labelled-set entries (S2.4.3) once the person agrees the file may be kept for that.
