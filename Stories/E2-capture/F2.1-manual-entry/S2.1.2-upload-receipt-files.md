# S2.1.2 Attach receipts, manuals, photos

**Feature:** F2.1 Manual purchase entry  
**Phase:** MVP  
**Milestone:** M3  
**Depends on:** S7.6.3 (Private file storage); S2.1.1 (Add a purchase with one or more items)  

As a **user**, I want to upload the receipt and other files to a purchase or item.

## Acceptance criteria
- PDF and image types accepted
- Size and count limits enforced
- Files stored privately, served by signed URL


## Status
Done (M3) with local-disk storage behind IFileStore (swap for S3 or R2 on Render). Files are identified by their first bytes (PDF, JPEG, PNG, WebP, HEIC), limited to 10 MB and 20 per purchase or item, private to the account, and removed with the purchase. Phone camera via file input with capture. Account deletion still needs to delete stored files (S1.4).
