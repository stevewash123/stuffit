# S2.7.5 Date from a serial number

**Feature:** F2.7 Partial data and uncertain facts  
**Phase:** v2  
**Milestone:** M6  
**Depends on:** S2.7.2; S7.5.1 (DDL: reference data schema)  

As a **user**, I want the manufacture date read from the serial number so I know the unit cannot be older than that.

## Acceptance criteria
- Curated, versioned per-maker decode rules (reference data): pattern, where the year and week/month sit, the century/rollover rule, and the source of the rule
- Result is a manufacture date (or month/year) used as the earliest possible purchase date; never as the purchase date itself
- Rule confidence: verified against known units / source-cited / unverified; unverified rules are not applied automatically
- A serial that matches no rule, or matches several, returns nothing and says so
- Operator screen to add and test rules against example serials (E7)
- Seeded for the makers in the starter data where rules are public; the rest are added when asked for
- Ship rules for the common appliance and HVAC makers first; no guessing for others

## Notes
Pattern: maker-specific. First targets: HVAC (compressors, furnaces), water heaters, appliances.
