# S2.7.2 Evidence behind a fact

**Feature:** F2.7 Partial data and uncertain facts  
**Phase:** v2  
**Milestone:** M6  
**Depends on:** S2.7.1; S2.1.2 (Attach receipts, manuals, photos)  

As a **user**, I want to see why StuffIt believes a date, model or seller, and add proof.

## Acceptance criteria
- An evidence record: item or purchase, field (date, seller, model, serial, installer), value or range, source type (receipt, email, manual, nameplate photo, serial decode, retailer record, statement, permit, photo date, user memory, estimate), attached document, who added it, when
- A field can have several pieces of evidence; the one shown is the strongest (documentary beats decode beats memory beats estimate); order is a documented rule
- The item page shows each fact with a confidence label (confirmed, likely, estimated, unknown) and a "why" that opens the evidence
- Adding better evidence changes the shown value and keeps the old evidence (S2.7.12)
- Evidence is personal data: never shared, covered by export and account deletion (S1.4.1, S1.4.2)
- Pattern story: S2.7.5, S2.7.10 and S2.7.14 all write and read these records

## Notes
Pattern: provenance and confidence for any field.
