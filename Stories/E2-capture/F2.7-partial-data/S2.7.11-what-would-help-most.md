# S2.7.11 Ask for the one fact that helps most

**Feature:** F2.7 Partial data and uncertain facts  
**Phase:** v2  
**Milestone:** M6  
**Depends on:** S2.7.2; S3.1.6; S9.2.3 (Item detail)  

As a **user**, I want to be asked for only the missing fact that actually changes my coverage.

## Acceptance criteria
- For each incomplete item the app works out which single missing fact would settle the most coverage (for example "the purchase year settles 2 of 3 coverages")
- The item page and New Items row show that one prompt, not a form full of blanks
- Facts that change nothing (for example colour) are never prompted for
- The prompt can be snoozed or dismissed ("don't ask about this item"); a snooze is a user choice and not a lost reminder
- Digest and Home count incomplete items without nagging: a gentle, capped nudge (S4.2.1)

Pattern: prompt ranking.
