# S4.2.1 Digest content and frequency

**Feature:** F4.2 Digests and consolidated notifications  
**Phase:** v2  
**Milestone:** QA  
**Depends on:** S4.1.2 (Daily job sends due reminders); S2.2.3 (Needs-info review queue); S4.2.3 (Digest batch job)  

As a **user**, I want to a single summary, only when something changed.

## Acceptance criteria
- Each message type has a delivery mode in the preference grid (S4.4.2): Instant, Daily digest, or Weekly on a chosen day; the digest lists the types set to daily or weekly
- Content like: X purchases added, Y need info, Z expiring soon, with deep links
- No email when there is nothing to report
- Digest time of day and timezone are per user

Update 2026-10-19: Error-level items (high value, still unresolved) go in the digest with the return-window closing date, using the recipient's own minimum. The rules (colours, the two values of a line, per-person minimum, dismiss confirmation) are in S9.2.11.
