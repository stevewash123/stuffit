# S4.2.2 Urgent deadlines bypass the digest

**Feature:** F4.2 Digests and consolidated notifications  
**Phase:** v2  
**Milestone:** QA  
**Depends on:** S4.2.1 (Digest content and frequency)  

As a **user**, I want to be warned promptly about return windows about to close.

## Acceptance criteria
- Coverages ending within ~3 days send immediately regardless of delivery mode
- Not duplicated in the next digest

## Status

2026-11-02 (feat-digest, API, not merged): Done for coverages. A coverage notice with 3 or fewer days left (`DigestComposer.UrgentDays`) is sent with `Urgent` and is never held, whatever the person's mode; it is emailed at once, so it is `Sent` and is not in the next digest. Important notifications (`IsImportant`) bypass the same way. To-do nudges are not treated as urgent. Tests: `DailyDigestTests.A_closing_within_three_days_is_emailed_at_once_and_not_repeated_in_the_digest`.
