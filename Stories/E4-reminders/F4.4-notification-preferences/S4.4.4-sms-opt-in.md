# S4.4.4 SMS opt-in and verification

**Feature:** F4.4 Notification preferences (message type x channel)  
**Phase:** v2  
**Milestone:** M8  
**Depends on:** S4.4.3 (Dispatcher: store preferences and enforce them on every send)  

As a **user**, I want to receive text alerts only after verifying my phone and consenting.

## Acceptance criteria
- Verified phone number required before SMS toggles enable (phone, verified flag and verified_at stored)
- Explicit consent text stored with timestamp
- STOP and START keywords handled; opt-out reflected in the grid
- Carrier registration and per-message cost reviewed before launch
- Only high-value types offered by SMS by default (e.g. return window closing)
- Every SMS includes a link to more information (S4.4.10)

## Notes
ConsignmentGenie stubs SMS sending (logs only) and treats any phone number as verified in one path.
