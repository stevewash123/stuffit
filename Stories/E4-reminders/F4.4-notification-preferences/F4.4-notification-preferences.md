# F4.4 Notification preferences (message type x channel)

**Epic:** E4 Reminders & Notifications  
**Phase:** MVP

A grid where the user chooses, for each message type, which channels deliver it (Email, SMS, In-app) and how (instant or batched). Modeled on ConsignmentGenie (UI matrix screen and API NotificationPreferenceService, EmailComplianceService, DefaultSettingsService), de-duplicated and hardened (see docs/consignmentgenie-lessons.md).
