# S4.4.2 Notification preference grid

**Feature:** F4.4 Notification preferences (message type x channel)  
**Phase:** MVP  
**Milestone:** M4  
**Depends on:** S4.4.3 (Dispatcher: store preferences and enforce them on every send); S9.8.1 (Settings page); S4.5.3 (Notification Center page)  

As a **user**, I want to turn each message type on or off per channel and choose how it arrives.

## Acceptance criteria
- Contact section above the grid: primary email and phone number
- Grid: rows = message types grouped under category headings, columns = Email, SMS, In-app
- SMS checkboxes disabled until a verified phone number exists; In-app column live from MVP; SMS shows coming soon until S4.4.4 ships
- Per-type delivery mode selector where it makes sense: Instant, Daily digest, Weekly on a chosen day
- Mandatory rows (System Alerts) shown locked with a reason
- Each toggle saves immediately with a visible status: Saving... then Saved automatically; failures show an inline error and revert
- Lead-time fields (days before expiry) next to expiry types, with help text
- Every checkbox has a screen-reader label naming the type and channel; grid reflows to stacked rows at phone width
- Sensible defaults on first use; Restore defaults action
