# S4.5.7 Real-time updates and toasts

**Feature:** F4.5 Notification Center (in-app)  
**Phase:** v2  
**Milestone:** QA  
**Depends on:** S4.5.6 (Keep the unread count current)  

As a **user**, I want to see new notifications appear as they arrive.

## Acceptance criteria
- Server-sent events or WebSocket channel pushes new notification and unread count events
- Optional toast for important new notifications, with auto-dismiss and a link
- Reconnect with backoff and no duplicate connections
- Falls back to the polling in S4.5.6 if the connection is unavailable

## Notes
ConsignmentGenie uses SignalR (NotificationHub: UnreadCountUpdated, ToastNotification); its UI reconnect logic can stack duplicate connections, so guard against that.
