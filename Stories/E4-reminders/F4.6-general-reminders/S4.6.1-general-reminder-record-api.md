# S4.6.1 General reminder record and API

**Feature:** F4.6 General reminders (to-dos)
**Phase:** MVP candidate
**Milestone:** M6 (proposed)
**Depends on:** S4.1.1 (the existing reminder pattern); S2.1.2 (documents)

As a **user**, I want a place for things I need to do about something I bought, so they do not depend on my memory.

## The record
A **reminder** (stored as a to-do) belongs to the account and optionally to an item, a purchase and the document it came from.

| Field | Meaning |
|---|---|
| kind | What sort of thing: register warranty, rebate, keep something, check something, other. Used for an icon and grouping; nothing depends on it |
| title, body | Plain words, written by the user or the review process. Title up to 200 characters, body up to 2000 |
| url | An optional link ("register here") |
| dueOn | Optional date by which it must be done |
| remindFrom | Optional date to start nudging; defaults to a few days before dueOn |
| status | **suggested** (found by the system, not yet accepted), **open**, **snoozed** (dismiss for now, with a come-back date), **done**, **dismissed** (not applicable or wrong) |
| snoozedUntil | When a snoozed reminder comes back |
| source | user, document review, system |
| confidence, evidence | For found reminders: how sure, and the quote or page it came from |
| sourceDocumentId | The document it was read from, if any |
| details | A free JSON object for kind-specific properties. Empty for now; specific kinds add keys here and are promoted to columns later if needed |
| completedAt, createdBy | Audit |

## Acceptance criteria
- Create, edit, list and delete a reminder (user source). Items and purchases are checked to belong to the account.
- Actions, each one call: **done**, **snooze** (until a date; default 7 days), **dismiss**, **accept** (suggested to open), **reopen**.
- A snoozed reminder counts as open again once its date passes; no job needed to flip it.
- The list can be filtered by item and by status; the default is what needs attention: open, snoozed that are back, and suggested ones shown separately.
- Tenant-scoped like all user data. Deleting an item or purchase removes its reminders.
- Included in the data export and removed with the account (S1.4.x).
- Any unknown kind is stored and shown as Other.
